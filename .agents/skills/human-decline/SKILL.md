# Human decline

The owner declines an Idea. You apply the labels and close the issue; the owner does not. Only the owner invokes this skill, so never call it yourself.

The rule lives in the "Owner words" section of the Next steps runbook of `trajectonomics/factory`, so it is changed there and never here.

1. **Find the issue.** The argument is `<repo>#<n>`, `trajectonomics/<repo>#<n>` or an issue URL, then an optional reason. With no argument, list the owner's queue (open issues labelled `idea-for-human`, then `idea`, then `idea-postponed`, across `trajectonomics`, with `gh search issues --owner trajectonomics --state open --label <label> --json repository,number,title,url`) and ask which one.
2. **Read the rule** from `origin/main` of `factory`: `gh api repos/trajectonomics/factory/contents/docs/next-steps-runbook.md -H "Accept: application/vnd.github.raw+json"`. Read "Idea lifecycle" and "Owner words" and follow the row for `decline`.
3. **Check the issue.** It must be open and carry `idea`, `idea-for-human` or `idea-postponed`. Otherwise say so and stop; change nothing.
4. **Get a reason.** If none was given, ask the owner for one short sentence. The finder reads it so that it never proposes the same thing again.
5. **Apply the row.** Remove the idea labels it carries and add `wontfix`. Comment `> *This was generated by AI during triage.*` then `Owner declined: <reason>`. Close the issue as not planned (`gh issue close <n> -R trajectonomics/<repo> --reason "not planned"`). The issue stays on record.
6. **Say what you did** in one line with the issue URL.
